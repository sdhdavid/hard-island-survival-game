# אחרי הסערה

משחק הישרדות וחקירה דו־ממדי שרץ בדפדפן. אין בו תלויות, שלב בנייה או קובצי גרפיקה: כל האי, המים, העצים, האור והקולות נוצרים בקוד (Canvas 2D ו־Web Audio).

התעוררת על חוף אחרי סערה. התרמיל שלך תלוי על ענף מעל המים, הסירה הכחולה תקועה על השונית, ומעבר לצמרות מבצבצת אנטנת רדיו.

## איך מריצים

הקבצים סטטיים, אבל צריך להגיש אותם משרת מקומי:

```bash
python3 -m http.server 8123
```

ואז לפתוח את `http://localhost:8123/`.

## שליטה

| מקש | פעולה |
| --- | --- |
| WASD / חצים | תנועה (או לחיצה על הקרקע — הדמות מוצאת דרך לבד) |
| Shift | ריצה |
| E / רווח | פעולה ראשית ליד חפץ |
| R | פעולה שנייה (למשל חיתוך סיבים, מילוי בקבוק) |
| C | יצירה |
| N / M | מחברת: משימות, מפה שמתמלאת, גילויים |
| T (החזק) | לתת לזמן לעבור (למשל לחכות לשפל) |
| 1–9 | שימוש בחפץ: לאכול, לשתות, להחזיק לפיד |
| Esc | תפריט: טעינה, עזרה, השתקה |

במכשיר מגע מופיעים ג׳ויסטיק וכפתורי פעולה.

## מה יש באי

- **שני שבילים:** אחד מטפס מהחוף אל מגדל הרדיו ומסומן בערימות אבנים. השני עוקב אחרי הפלג, עובר במחנה הנטוש ובמעיין, ומגיע לבריכת הסלע.
- **גאות ושפל:** הים עולה ויורד כל שש שעות משחק. בשפל המים נסוגים מבריכת הסלע ונחשף מדף שמוביל למערה. לרמזים שווה להסתכל על קו האצות על הסלע, על קצף הגלים ועל הנצנוץ בתוך הפתח.
- **הישרדות:** מים, אוכל ואנרגיה. המדורה היא הבית: מבשלים בה, נחים לידה, ישנים עד הבוקר, וכל מנוחה **שומרת את המשחק**.
  - **בחוף:** עצי סחף בשפע שהים מביא כל בוקר, אבל רוח שמכלה את האש.
  - **ליד המעיין:** מים וצל, אבל רחוק מהסירה.
  - **במחנה הנטוש:** מחסה ובור אש מוכן.
- **כלים שפותחים את העולם:**
  - **חבל** מסיבי דקל: מושכים בו את ארגז החירום מהסירה, ובו המצבר.
  - **מדורה:** בישול, מנוחה ושמירה.
  - **לפיד** מענף, סיבים ושרף, שמדליקים ליד אש: חושף במערה ציורים וסימני גיר שמובילים אל הנתיך.
- **המטרה:** להתקין מצבר ונתיך (בכל סדר), לסובב את חוגת התדר עד שקול אנושי עולה מתוך הרעש, לשדר קריאת מצוקה, ולחזור לחוף לראות את אורות סירת החילוץ מעבר לשונית.

## בדיקות

שתי בדיקות Playwright מריצות את המשחק עצמו, דרך חוקי התנועה, ההתנגשות והגאות האמיתיים:

```bash
npm install
npx playwright install chromium   # only if no Chromium is installed yet
python3 -m http.server 8123 &
npm test
```

- `tests/playthrough.js`: מסלול מלא מהחוף ועד החילוץ. כולל בנייה, הגעה לסירה, מחנה, לפיד, המתנה לשפל, המערה, שמירה ליד מדורה, **טעינה מחדש של הדף וטעינת השמירה**, תיקון הרדיו, כיוון התדר בגלגלת העכבר, קריאת מצוקה ומסך הסיום.
- `tests/systems.js`: סרטנים שמתחבאים, אתר מחנה בחוף, בישול, שינה עד הבוקר (כולל שמירה), עצי סחף חדשים בבוקר, צדפות באזור הגאות, המתנה, והתעלפות שמחזירה למחנה.
